Programar uma placa

Isto é o atalho de emergência. O melhor é usar a aba Placa da app.

1 · Testar primeiro
2 · Escrever isto na placa

NFC Tools → Write → Add a record → URL/URI → colar → Write.

3 · Proteger

Depois de tocar com o telemóvel e confirmar que abre: NFC Tools → Other → Set password → password mestre. AUTHLIM desligado.

Nunca carregues em «Lock tag» ou «Make read-only». Não tem volta e um dia vais precisar de mudar o link.
