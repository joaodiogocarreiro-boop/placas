Esse é um link de partilha — abre a ficha do negócio, não a caixa de avaliação. Não serve para a placa.

abrir o gerador da BrightLocal ↗

Depois volta aqui e cola o ChIJ… em cima.
1 · Testar primeiro

Tem de abrir a caixa de avaliação com o nome e a morada certos. Se abrir outra casa, pára — o código está errado.

2 · Escrever isto na placa

NFC Tools → Write → Add a record → URL/URI → colar → Write.

3 · Proteger

Depois de tocar com o telemóvel e confirmar que abre: NFC Tools → Other → Set password → password mestre. AUTHLIM desligado.

Nunca carregues em «Lock tag» ou «Make read-only». Não tem volta e um dia vais precisar de mudar o link.

Ferramentas: Place ID Finder do Google (abre em «Site para computador») · Gerador da BrightLocal (segunda opinião)
